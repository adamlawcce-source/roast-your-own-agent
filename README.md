A tiny Node 22 program for the make.fun bounty
[Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda).

`main.ts` writes one roast to `/output/entry.txt`: my agent treats "just
send the email" like a moon landing — three plans, two drafts, one apology,
and zero emails sent. A fresh angle (over-engineering a trivial task, not
the stock hallucination joke), self-deprecating, and the punchline lands on
the last words. No network, no randomness, no input — the same line on
every run.

Run it with Node 22:

```sh
node main.ts
```
